# 🎓 Student Management System (Flask + MySQL)

## 🧩 Problem Statement

Managing student records manually or using spreadsheets becomes inefficient, error-prone, and hard to scale as the number of students increases.  
A **web-based automated system** streamlines data management, ensures accuracy, and allows for faster access and manipulation of student information.

---

## 🚀 Features

- ➕ **Add** new student records seamlessly  
- 📋 **View** all student entries in a clean, tabular format  
- ✏️ **Update** existing student information with ease  
- ❌ **Delete** records securely and efficiently  
- 🔍 **Search** students by ID or name instantly  
- 🧑‍💻 Intuitive and **user-friendly interface**

---
