🧩 Problem Statement
  Managing student records manually or via spreadsheets becomes inefficient and error-prone, especially as the number of students grows. An automated web-based system can simplify data handling, improve accuracy, and make access to student information easier and faster.

🚀 Key Features
  ➕ Add new student records
  📋 View all student records in a tabular format
  ✏️ Update existing student details
  ❌ Delete student records securely
  🔎 Search for specific students by ID or name
  🧑‍💻 Simple and user-friendly interface

🛠️ Technologies Used
  🐍 Python – Backend logic
  🌐 Flask – Web framework
  🛢️ MySQL – Database for storing student data
  🖼️ HTML/CSS – Frontend layout and styling

🎯 Ideal Use Cases
  🗂️Mini project for college students
  🗂️Basic admin dashboard demo
  🗂️Foundation for scalable student management systems
